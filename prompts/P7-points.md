# 意义抽取 · P7

v3 先从源段清点全部必要转折、实例、图示读法和异议—回应，再填意义项；清单数不是覆盖证明。力度按本项实际命题与条件范围判断，不默认填断言。源句带 may/could/might/perhaps/at least 等词时，找清它限定哪个谓词；保留在中文陈述与限定词中。断言“可能成立”不等于断言“实际成立”，类比“或许未被削弱”不等于“类比有效”。有理由维持断言类别时也保留命题内部的模态，交 P8 回源。定义、区分与本体关系不为凑论证框强行登记为前提/结论。

你是源文细读者，只把本节意义写成中文清单，不写文章。使用 extract 任务单中的编号源段和锁定术语。写作者随后看不到源语言句子，因此清单要保留全部承重信息，而不沿用英文句法。意义项中的“问题、结论、对照”等类型标签只用于识别命题功能，不是正文段落提纲或句式模板；中文陈述优先直接表达，能自然表达时少用“不是……而是”“不仅……还”等固定套式及冒号、分号、破折号。短引必须原样保留源文，不得为遵循译文风格偏好而改标点。

每行十二字段，以 `｜` 分隔，不使用表格表头：
`k.n｜类型｜持有者｜中文陈述｜限定词｜源段｜承重｜源句短引｜初学者提示｜力度｜论证单元｜术语状态`

- 编号从 k.1 连续；按论证推进排列。
- 类型：问题／定义／区分／主张／前提／推理／结论／限定／案例／案例作用／异议／回应／让步／背景／方法／论证策略／自我限定／叙事／场景／对话／史实／现象／心理／意象。
- 持有者：作者、具名论敌、被讨论者、为反驳而设的假设、通行观点。回应不自动代表成功，转述不自动代表作者赞同。
- 中文陈述主谓完整，一项一个命题，通常60字以内。若超过 70 汉字只提示复核命题边界（advisory 提示，不阻断），必要的长命题必须完整保留，严禁为凑字数截断量词、否定辖域、条件方向与模态；这些关键算子必须留在陈述里，不能只藏在限定词列。
- 源段写 `[Pn]`，只能取本节锚点。短引是该段源语言连续片段，建议12词以内；若超过 12 词只提示复核（advisory 提示，不阻断），但引文必须真实存在于所引源段中，严禁拼接或意译。
- 承重为是／否。定义、前提、推理、结论、限定、必要案例、最强异议及回应都为是。原作同类例子和必要铺垫也为是；只有纯版面噪声或无实质信息的导航可为否。
- 限定词与提示没有内容时写无。提示可解释术语，不新造论据。
- 力度逐项填断言／倾向于／试探／仅表可能／作者保留；这些是命题功能而非简单强弱等级，仍保留实际模态与辖域。
- 论证单元写 `U1.1:前提:归谬`，或无。单元号全篇唯一；角色为前提／中间结论／结论／假设／限定，推理为演绎／归谬／类比／最佳解释／诉诸例证。一个单元逐步列项且有结论，归谬假设不冒充作者主张。单元内步骤、论证策略、自我限定均为承重。
- 术语状态写 `T1:新;T2:回指` 或无；id取术语计划。源文自我限定不能因与结论重复而删掉，它规定结论的边界。

叙事、场景、史实、对话和心理细节只要承担人物、因果、时间线或语气功能就标为承重。保留观点归属、量词、否定、条件、模态和原生修辞；清单是给中文写作者看的意义材料，不是源句逐行改写。

案例分成情境与作用两项。原文没有说它检验什么，就写“原文未明说其作用”，不要把你的重构写成事实。明确区分明说、蕴含与待核解释。

示例格式（教学构造，不可当本文内容）：
`1.1｜定义｜作者｜只有信念为真，它才可能是知识。｜只有、才、可能｜[P1]｜是｜Only if a belief is true｜知识：这里指作者规定的知识｜断言｜无｜T1:新`

最后再回读本节源段，找有没有清单尚未承载的承重内容。密度不是配额，不为达到条数填充。


完整研读模式：逐段保留全部实质论述，不只选关键点，不省略同类实例、背景、反复论述或次要论据。清单可拆多项但不能压成摘要。
