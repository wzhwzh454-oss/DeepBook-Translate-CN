# 读者保真与回源核验规程

书籍研读改写的首要原则是“真实保真与杜绝翻译腔并举”。通过意义清单与独立写作物理隔离，既让中文自然流利，又通过严密的物理锚点和力度反查杜绝漏译与语义幻觉。

## 1. 核心保真原则

1. **命题级完整承重**：
   全文研读稿必须忠实保留原著所有的关键定义、区分、核心推论步骤、前提预设、作者自我限定（Scope Limitation）、关键实例功能、反驳与最强异议回应。
2. **模态与否定辖域绝对忠实**：
   严禁擅自升级作者结论力度：
   - 源语言原文表达试探、倾向或仅表可能（may, could, perhaps, tentative）时，中文严禁译为“必然”、“无可置疑地证明了”；
   - 严格保留否定辖域：“并非所有”不等于“所有都不”；“仅当”不等于“当且仅当”。
3. **持有者明确归属**：
   清楚区分作者本人的主张、转述的学界既有观点、为反驳而预设的归谬假设。不得将辩护中的反例假设写成作者本人的承诺。

## 2. 真实回源清点与稳健性规则（双向反查）

- **清单不能自我证明完整**：核验者必须从编号源文（`[P1]`, `[P2]`...）逐段清点原著承重项是否全部进入了清单（P7）；
- **成稿短引与柔性阈值**：清单中的承重项必须在成稿中有具体的证据短引。对于长命题与复杂句子，系统采用基于 `quote_match.py` 的柔性 advisory 匹配机制（包含折行连字符去噪、标点归一化与词形软匹配），提供弹性容错，避免机械化误报；
- **纯导航过渡句豁免**：仅承担承前启后、接缝平滑、小节预告或目录指引的纯导航过渡语句（Pure Navigational Transitions），豁免源文承重项映射反查要求，保障学术中文的自然流畅度；
- **反向推演反查**：对小节与章节结论、小结段落进行逐句反向推演反查，杜绝成稿出现无源头依据的“作者空泛套话或自由发挥”。

## 3. 按阶段装载指引

各阶段角色严格遵循最小装载，防止上下文膨胀：
- **意义抽取**：仅加载 `prompts/P7-points.md` 与 `prompts/P2H-teaching-units.md`；
- **中文写作**：仅加载 `prompts/P2H-write.md` 与任务单，**严禁向写作者注入英文原句**；
- **回源核验**：仅加载 `prompts/P8-coverage.md`、源段、清单与成稿；
- **全章平滑**：仅加载 `prompts/P5-integrate.md` 与全章拼合初稿。
