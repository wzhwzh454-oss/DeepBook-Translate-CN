# 文章保真：源侧清点、讲解单元与真实回源

### 1. 源侧清点与术语

沿用 S0 编号、S1 大纲、S1.5 term-plan。按原文清点定义、概念转折、推理及隐含前提、作者自我限定、关键实例、图表读法、每一对异议—回应。每个源段都须被查看，致谢、参考文献等只需说明不纳入的原因。不要靠清单点数宣布覆盖完整，也不拆出三百条细碎项目来达密度指标。

源为 PDF 时先核提取是否保留承重脚注、图注与关键图；编号稿里根本没提取到的内容不会被逐段覆盖检查发现。有文本与 PDF 词数差异先核提取口径，不把差异直接说成漏页或优化效果。核心图片的读法仍回实际原图，不靠图号猜。

译名表同时约束正文、导读、论证梳理、PPT 与讲稿。普通碰撞按学科语境自行解决；已给的明确译名不擅自解锁。遇到实质改变概念边界的冲突才向用户确认。术语卡分清“概念是什么”和“作者用它做什么”；后者不能充当定义。首次解释用何种方法取决于概念，不强制统一句式。

### 2. 按讲解单元写作

P7 抽取之后，读取 engines/translation/prompts/P2H-teaching-units.md，为本节建立 {k}-teaching-units.json。每个单元处理一个读者难点，可以跨多个清单项；全体单元须覆盖本节承重项。每个单元说清问题、讲解目的、原文实例、方法、先后与限定，而不是直接给一段可以贴进正文的答案。

build_task_sheet.py 的 write 模式加 --teaching-units <绝对路径>。脚本验证承重项不丢失，并将中文证据材料嵌入单元；不把英文源句和学习记录带入写作任务。读取 P2H-write、P2H-expansion 与范文，按单元的解释路线自然写作。保留谁主张什么以及模态、条件、量词和否定范围；用中文组织句子，不把记录字段逐条照抄。

可选解释方法：先用普通问题进入抽象概念；用原文的正反例划边界；先呈现实例再命名；对照易混词；拆解某条推理为何成立；把条件与结论分别说清。例子须说明它检验了哪一步。原文案例不得被自造例子偷偷替代。真正新增的常识解释或类比单列“〔补充〕”，说明是阅读辅助，不参与忠实层计数；无需机械限制只能两段，也不让补充淹没原文。

### 3. 双向回源，不让清单自证

沿用 P8 与 check_coverage/check_force/check_terms。还要从原文逐段、按完整单元回查稿件，生成 source-audit.json：发现清单漏抽时先修清单；发现正文缺项时补写；发现力度升级或错归属时重写对应句。完整的源单元指所有承重步骤都已覆盖，不是只出现相同术语。

source-audit 在抽取时先形成源侧目录，定稿后填入当前映射与散列。source_sha256 和 article_sha256 均为 UTF-8 文本 SHA256，正文词数由标为 body 的原文段落机械计算。不要从成稿反向编造源目录。每对异议—回应、关键实例、转折理由及核心图各自一项；非承重背景可以说明后省略。

source-audit 的结构：

    {
      "source_sha256": "编号原文的散列",
      "article_sha256": "最终 chapter-final.md 的散列",
      "paragraphs": [
        {"id":"P1","scope":"other","reason":"题名与作者信息"},
        {"id":"P2","scope":"body","status":"covered","point_ids":["1.1"]},
        {"id":"P3","scope":"body","status":"nonbearing","reason":"具体非论证性背景"}
      ],
      "units": [
        {"id":"O1","kind":"异议回应","paragraph_ids":["P2"],"point_ids":["1.1"],"status":"完整","required_in_ppt":true},
        {"id":"F1","kind":"图示","figure_number":"1","paragraph_ids":["P4"],"point_ids":["2.1"],"status":"完整","required_in_ppt":true}
      ],
      "semantic_issues": []
    }

这是字段示例，不是可直接通过的论文目录。paragraphs 必须对应全部编号段落且不重复。body 中 covered 是完整对应；nonbearing 要有具体理由；excluded 还须 bearing=false，否则全文交付阻断。missing 或未处理的语义问题不能通过。units 的 id 只留审计，不进入读者成品。示例、回应、图示等单位按实际论文识别，不由模型页模板反推。原则、概念放宽的理由与研究纲领是否需要单列，按其在原论证中的作用判断。

### 4. 忠实层足够展开

全文稿忠实层汉字数 /（英文原文正文词数 × 1.7）低于 0.75 时提示复核展开程度；0.9–1.3 是初始参考，不是交付门禁。正文包括有原文依据的中文解释，不包括补充、导读、术语表、梳理框或小结。1.7 是中文研读稿的粗估计，不是等义或全译证明，也不适用于直接给非英文材料定字数。

篇幅预警后回看关键定义、推理、案例作用及异议—回应；有缺项或解释不足才补写，齐全且清楚就保留，在现有审计中简述判断，不另设审批。不能通过重复、赞美、扩写常识或把辅助层改成 Normal 样式凑够字数。指标变长也不证明内容完整。语义核验发现的缺项、错义、力度或归属变化，无论总覆盖率多高都先修复。
